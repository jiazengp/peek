# Changelog

## v2.0.0 (2026-07-08)

### Breaking Changes
- Drop support for Minecraft 1.21.x; now requires Minecraft 26.1+
- Require Java 25 (was Java 21)
- Require Fabric Loader >= 0.18.0
- Fabric API is now a required dependency

### Added
- Support for Minecraft 26.1, 26.1.2, and 26.2
